# Decisions

## 2026-10-19: Static content and limited dependencies
Astro7 and Markdown collections keep project writing independent of components. Native CSS and small TypeScript controllers handle the game-inspired shell without turning case studies into an inaccessible canvas. Node24 and exact dependency versions reproduce the environment. TypeScript6.0.3 satisfies the checker's peer contract.

## 2026-10-19: Reference fidelity has an evidence boundary
Use the observed menu hierarchy, shared scene and staged entrances, while retaining normal web routes. The game executable inspection establishes PE metadata only. Visible transition measurements are not engine curves or input latency. No extracted game assets are runtime dependencies.

## 2026-10-19: Privacy and placeholders
No account, server, tracking or contact submission service. Sound and motion preferences use optional local browser storage and tolerate failure. Example profile/content remain explicit, and indexing is disabled until the owner replaces the profile and opts into a public launch.

## 2026-10-19: Browser findings corrected
Native preference controls remain actual checkboxes; their decorative capsule layer must not intercept pointer input. On a direct/reloaded hash route, wait for fonts then position the actual section so initial layout and client-router restoration do not lose the target. Decorative footer words are artwork rather than low-contrast reading content. Mobile artwork starts below the identity copy.
