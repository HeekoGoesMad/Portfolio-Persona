# Design contract

Reading: recruiter-facing developer portfolio, Reload-led kinetic typography and shared blue scene. Design variance8, motion6, density4. This is a custom aesthetic, not an official Persona design system.

- Primary job: identify the developer and open a project immediately.
- Typeface: self-hosted Barlow Condensed bold italic for display; DM Sans for readable content.
- Color: deep blue/cyan scene, off-white typography, navy controls, pink edge accent. Solid surfaces; no generic gradient cards.
- Geometry: sharp panels and angled display framing. Body copy, article content and form labels stay upright.
- Layers: scene0, content1, sticky navigation10, dialogs100. Modal native top layer supersedes page layers.
- Home: typographic identity left; original large abstract figure right; project menu bridges the composition; featured content below.
- Projects: selection list and large concept-art preview; mobile stacks preview and list. Case studies scroll normally.
- Interaction states: hover, visible focus, selected item, filter-empty, unavailable optional links, missing thumbnail fallback.
- Motion: selection120ms, panel240ms, page360ms, ease-out. Selection occurs immediately. Animations communicate focus/change/hierarchy, never delay content access.
- Reduced motion: system reduction is always respected. User can request additional reduction. No looping animation, scroll hijacking, cursor replacement or forced intro.
- Original illustration is a geometric faceless silhouette, not a portrait or a game character. Example project covers are conceptual graphic artwork, not product screenshots.
- Keep English sample content explicit. Do not invent real achievements, contacts or résumé material.
