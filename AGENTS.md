# Project conventions

Read `tasks/plan.md`, `tasks/todo.md` and `docs/verification.md` before continuing.
Use Node 24.11.1+ and npm; install the lockfile with `npm ci`.
Commands: `npm run dev`, `npm run check`, `npm run build`, `npm test`, `npm run audit:site`.
Keep the application static and content-driven. Do not add a backend or publish without a user request.
Never invent personal facts or remove example labels from illustrative projects.
Actual game-derived assets and supplied reference captures are authorized for this local Persona revision; preserve their provenance and do not modify the original installation. Preserve content slugs, accessible links and reduced-motion behavior.
All changes to behavior require focused verification. Keep docs and the checklist honest.
Do not overwrite unfinished plans for other work. Do not commit node_modules, dist, credentials or test artifacts.
